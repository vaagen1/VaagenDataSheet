VaagenCal Help

About VaagenCal

VaagenCal displays instrument Tags and calculates values for a 4–20 mA signal range.

Select a Location and Tag to view the saved Description, Unit, LRV, URV, RA and alarm values.

VaagenCal can be used in two ways:

  1. Enter data on a PC and print data sheets for use in the field.
  2. Enter data directly on an iPhone or iPad and use the device in the field to view values.

Important:

  • Data is not synchronized between devices.
  • Clearing browser data may remove the local database.
  • On iPhone or iPad, add VaagenCal to the Home Screen and always open it from the FV icon.

Functions

  • The Location list selects the active Location.
  • The steel Tag plate displays the active Tag.
  • Press the left or right arrow once to move one Tag.
  • Press and hold the left or right arrow for 0.5 seconds to browse Tags automatically.
  • The three-dot button opens Tag Actions.
  • RA is calculated from URV minus LRV.
  • The tables show percentage, process and mA values.
  • The slider and minus/plus buttons simulate a 4–20 mA value.
  • Press minus or plus once for one step, or press and hold for continuous adjustment.

Export Database

  1. Open Tag Actions and select Export Database.
  2. VaagenCal creates a dated JSON backup containing all Locations, Tags and saved values.
  3. Save or share the backup file using the options available on the device.
  4. Keep the backup file if data must be restored or moved to another device.

Import Database

  1. Open Tag Actions and select Import Database.
  2. Select a VaagenCal JSON backup file from the device.
  3. Select Merge to keep the current database and add Locations and Tags from the backup. Duplicate Tags in the same Location are skipped.
  4. Select Replace to remove the current local database and use only the selected backup. A second confirmation is required.
  5. Select Cancel to close the import without changing the database.

Moving to another device: Export the database on the old device, transfer the JSON file to the new device, then use Import Database on the new device.

Add and Edit Data

  • Use the plus button beside Location to add a Location.
  • Use Tag Actions to add, edit or delete a Tag.
  • A Location can only be deleted after all Tags under that Location are deleted.
  • Save stores the entered Tag values in the selected Location.
  • Export Database creates a JSON backup containing all Locations, Tags and values.
  • Import Database can Merge a backup with existing data or Replace the complete local database.

Search and Navigation

  • Search Tag searches within the selected Location.
  • Press * to use it as a wildcard in the search box.
  • Select a result to display that Tag on the main page.
  • Tags are shown in natural order, with numbers first and then A–Z.

Print

  • Print Tag prints the current main page on portrait A4.
  • Print All Tags prints the Tags for the selected Location as a landscape A4 table.
  • The report includes saved values, calculated RA, percentage values and mA values.

Install VaagenCal on this computer

Choose Chrome or Edge below. Install VaagenCal, then open it from the new FV icon.

Google Chrome

Top-right browser menu⋮
  1. Open the circled three-dot menu.
  2. Select Cast, save, and share.
  3. Select Install page as app.
  4. Confirm, then open VaagenCal from the FV icon.

Microsoft Edge

Top-right browser menu…
  1. Open the circled three-dot menu.
  2. Select Apps.
  3. Select Install this site as an app.
  4. Confirm, then open VaagenCal from the FV icon.

After creating the shortcut, press the button above once. VaagenCal will then open normally from that shortcut.
