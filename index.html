VaagenCal Help

About VaagenCal

VaagenCal displays instrument Tags and calculates values for a 4–20 mA signal range.

Select a Location and Tag to view the saved Description, Unit, LRV, URV, RA and alarm values.

VaagenCal can be used in two ways:

  1. Enter data on a PC and print data sheets for use in the field.
  2. Enter data directly on an iPhone or iPad and use the device in the field to view values.

Important: Each device and browser has its own local database. Data entered on one device is not automatically available or updated on another device.

Functions

  • The Location list selects the active Location.
  • The steel Tag plate displays the active Tag.
  • Press the left or right arrow once to move one Tag.
  • Press and hold the left or right arrow for 0.5 seconds to browse Tags automatically.
  • The three-dot button opens Tag Actions.
  • RA is calculated from URV minus LRV.
  • The tables show percentage, process and mA values.
  • The slider and minus/plus buttons simulate a 4–20 mA value.
  • Press minus or plus once for one step, or press and hold for continuous adjustment.

Add and Edit Data

  • Use the plus button beside Location to add a Location.
  • Use Tag Actions to add, edit or delete a Tag.
  • A Location can only be deleted after all Tags under that Location are deleted.
  • Save stores the entered Tag values in the selected Location.

Search and Navigation

  • Search Tag searches within the selected Location.
  • Press * to use it as a wildcard in the search box.
  • Select a result to display that Tag on the main page.
  • Tags are shown in natural order, with numbers first and then A–Z.

Print

  • Print Tag prints the current main page on portrait A4.
  • Print All Tags prints the Tags for the selected Location as a landscape A4 table.
  • The report includes saved values, calculated RA, percentage values and mA values.
